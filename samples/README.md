# Sample materials

Drop real course files here to use them as fixtures for real-API quality checks.
The contents of this folder are git-ignored (only this README and the `.gitkeep` files are tracked),
because course material is private and must never be committed.

- `materials/`: class materials, PDF or HTML (e.g. `01_ASVSP_Uvod.pdf`).
- `notes/`: personal notes, Markdown (e.g. `Predavanje - 01.md`).

Files pair by class number `NN`: `01_ASVSP_Uvod.pdf` goes with `Predavanje - 01.md`.
Notes are optional per class; a class can have materials only.
